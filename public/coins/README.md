# Euro coin images

Source and copyright: European Central Bank (ECB), Frankfurt am Main, Germany.

Images are downloaded unmodified from the ECB's [common sides page](https://www.ecb.europa.eu/euro/coins/common/html/index.en.html). They are served locally; playing the game does not request anything from the ECB. The game scales their displayed size proportionally to the real diameters listed on that page and uses CSS to blend their backgrounds into the page.

The ECB's [copyright terms](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html) permit free use of information obtained directly from its website with accurate reproduction and source attribution. The coin display includes a visible ECB credit.
